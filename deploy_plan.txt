二、本机开发环境配置
================================================================================

2.1  ~/.mavenrc（自动设置 Maven 使用 JDK 21）
     export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home

2.2  ~/trax-deploy.env（每次新终端 source 一次）
     包含: SERVER_IP, SSH_USER, MYSQL_USER, MYSQL_PWD,
           API_BASE_URL, AMAP_KEY, AMAP_ANDROID_SDK_KEY, AMAP_IOS_SDK_KEY,
           JAVA_HOME (= openjdk@21)

2.3  后端构建命令
     cd backend
     mvn -q -DskipTests package
     # JAVA_HOME 已由 ~/.mavenrc 自动指向 JDK 21，无需手动 export

2.4  后端部署命令
     source ~/trax-deploy.env
     scp backend/target/trax-backend-0.0.1-SNAPSHOT.jar \
         ${SSH_USER}@${SERVER_IP}:/opt/trax/current/trax-backend.jar
     ssh ${SSH_USER}@${SERVER_IP} \
         "sudo systemctl restart trax-backend && systemctl is-active trax-backend"

三、服务器关键文件
================================================================================

3.1  /etc/systemd/system/trax-backend.service
     [Unit]
     Description=TRAX Backend
     After=network.target

     [Service]
     User=root
     EnvironmentFile=/etc/trax.env
     Environment=JAVA_OPTS=-Xms256m -Xmx512m -XX:+UseG1GC -Dfile.encoding=UTF-8
     ExecStart=/opt/jdk21/bin/java $JAVA_OPTS \
               -Dspring.profiles.active=prod \
               -jar /opt/trax/current/trax-backend.jar
     Restart=always
     RestartSec=5

     [Install]
     WantedBy=multi-user.target

3.2  /etc/trax.env（示例结构，不含真实密钥）
     SPRING_DATASOURCE_URL=jdbc:mysql://127.0.0.1:3306/trax?...
     SPRING_DATASOURCE_USERNAME=<db_user>
     SPRING_DATASOURCE_PASSWORD=<db_pwd>
     JWT_SECRET=<jwt_secret>
     GOOGLE_MAPS_API_KEY=<gmaps_key>

3.3  Nginx 配置位置: /etc/nginx/conf.d/trax.conf
     - HTTPS → 反代 127.0.0.1:8080
     - /images/ → /var/lib/trax/images/
     - /download/ → /var/www/trax-download/

3.4  MySQL (Docker)
     运行在 127.0.0.1:3306，容器名 mysql（或 trax-mysql）
     连接: mysql -h127.0.0.1 -u<user> -p'<pwd>' trax

四、Flutter App 打包发布
================================================================================

4.1  APK + IPA 一键发布（推荐）
     cd trax_app
     source ~/trax-deploy.env
     ./scripts/release.sh              # 构建 APK + IPA，APK 自动上传到 /download/
     ./scripts/release.sh --ipa-upload # 同上 + 自动上传 IPA 到 TestFlight

4.2  命名规则（release_naming.sh）
     格式: trax-test-YYMMDD-NN.{apk,ipa}
     - YYMMDD = 构建日期 (Asia/Shanghai)
     - NN      = 当日序号，从 01 开始，APK/IPA 同一份代码共用同一 NN
     - 代码未变重复构建 → 复用同一 NN
     - 代码变更 → 自动递增 NN

4.3  TestFlight 上传（需 ASC API Key）
     在 ~/trax-deploy.env 中配置:
       export ASC_API_KEY_ID=<Key ID>
       export ASC_API_ISSUER_ID=<Issuer UUID>
     将 AuthKey_<ID>.p8 放在 ~/.appstoreconnect/private_keys/

4.4  APK 下载页
     http://43.99.48.204/download/
     最新 APK: http://43.99.48.204/apk/trax-latest.apk
     版本信息: http://43.99.48.204/download/version.json

4.5  iOS 版本信息更新（TestFlight 上线后执行）
     ./scripts/update_ios_version.sh           # 自动检测最新 IPA
     ./scripts/update_ios_version.sh 260518-01 "Bug fixes"  # 手动指定

六、Java 版本一致性确认
================================================================================

  本机构建 (Maven)   → JDK 21  (via ~/.mavenrc + Homebrew openjdk@21)  ✅
